## Placeholders

House-specific values are replaced with placeholders. Resolve them from the house environment or vault, never paste real values here.

- `$HOUSE_HOST`: the house workstation that runs the MCP stack, ComfyUI and the boxshell homes
- `$USER` / `~`: the machine user on the house workstation and its home folder
- `$HOUSE_MCP_URL`: the house full-catalog MCP endpoint (mcpproxy)
- `$EVE_HEART_URL`: the filtered daily-belt MCP endpoint (eve-heart)
- `$HOUSE_VAULT`: the Proton Pass vault name for house infra
- `$KEY_STORE_HOST`: the host part of the Technitium keyring entry name
- `$DNS_HOST`: the house Technitium DNS server
- "the house domain": the family's internal domain

Sage routes. This is the clean source for Grok.com pulls.
